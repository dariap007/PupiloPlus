# PupiloPlus

PupiloPlus — мобильное приложение для владельцев домашних животных. Оно помогает хранить информацию о питомце, следить за его возрастом, планировать напоминания и контролировать важные события в календаре.

## Назначение

Приложение предназначено для удобного учета данных о домашних животных, а также для организации регулярного ухода, лечения и профилактических процедур.

## Основные возможности

- добавление и редактирование карточек питомцев;
- хранение данных о породе, возрасте, весе и особенностях ухода;
- загрузка фото животного;
- расчет возраста по дате рождения;
- просмотр списка напоминаний;
- создание уведомлений по времени и регулярности;
- использование календаря для контроля событий.
