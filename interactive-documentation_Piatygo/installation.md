# Установка и настройка

## Системные требования

| Параметр | Требование |
|---|---|
| Интегрированная среда | Android Studio |
| Версия Java | 11 |
| Android SDK | актуальный набор платформ и инструментов |
| Минимальная версия Android | 5.0 (API 21) |
| Объем памяти | не менее 4 ГБ |

## Порядок установки

1. Скачайте и установите Android Studio.
2. Откройте проект PupiloPlus.
3. Дождитесь завершения загрузки зависимостей Gradle.
4. Подключите устройство или создайте эмулятор.
5. Выполните сборку проекта командой:

```bash
./gradlew assembleDebug
```

## Необходимые разрешения

Приложение запрашивает доступ к следующим функциям:

- уведомления;
- установка точных сигналов уведомлений;
- чтение изображений для загрузки фото питомцев.

> Важно: без разрешений часть функций приложения может быть недоступна.

## Первоначальная настройка

После запуска приложения пользователь может:

- добавить питомца;
- настроить напоминания;
- включить или отключить уведомления в разделе параметров;
- выбрать тему интерфейса.

## Работа с изображениями

Для фото животных приложение использует локальное хранение на устройстве. Это позволяет сохранять персонализированную карточку питомца без привязки к внешнему сервису.
