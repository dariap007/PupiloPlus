# Быстрый старт

## Шаг 1. Запуск приложения

1. Откройте проект в Android Studio.
2. Подождите завершения синхронизации Gradle.
3. Запустите приложение на эмуляторе или реальном устройстве.

## Шаг 2. Добавление питомца

1. На главном экране нажмите кнопку добавления питомца.
2. Введите имя и выберите тип животного.
3. Укажите дату рождения, породу и дополнительные сведения.
4. Сохраните карточку.

## Шаг 3. Создание напоминания

1. Перейдите в раздел напоминаний.
2. Нажмите кнопку добавления.
3. Укажите дату, время, тип события и периодичность.
4. Сохраните уведомление.

## Шаг 4. Проверка календаря

На главном экране отображается календарь. В нем отмечены дни, в которые назначены напоминания. Это позволяет быстро найти нужную дату.

## Пример команды запуска

```bash
./gradlew assembleDebug
```

Эта команда выполняет сборку проекта в режиме отладки. После сборки приложение можно запустить на устройстве.
