# Начало работы

## Системные требования

Для корректной работы приложения необходимо:

- Android Studio;
- Java 11 и Android SDK;
- устройство или эмулятор с Android 5.0+;
- разрешения на уведомления и доступ к хранилищу.

## Подготовка окружения

1. Скачайте и установите Android Studio.
2. Откройте проект из корневой папки `PupiloPlus`.
3. Дождитесь синхронизации Gradle.
4. Подключите устройство или запустите эмулятор.

## Сборка проекта

В корневой папке проекта выполните команду:

```bash
./gradlew assembleDebug
```

Для Windows:

```powershell
gradlew.bat assembleDebug
```

## Запуск приложения

После успешной сборки выберите устройство и запустите приложение через Android Studio.

## Разрешения

Приложение запрашивает:

- `POST_NOTIFICATIONS` — для отправки уведомлений;
- `SCHEDULE_EXACT_ALARM` — для точного планирования напоминаний;
- `READ_EXTERNAL_STORAGE` — для загрузки фотографий питомцев.

> Если разрешения не даны, часть функций может быть недоступна.

## Первые шаги после запуска

1. Добавьте питомца на главном экране.
2. Заполните данные и выберите фото.
3. Перейдите в раздел напоминаний.
4. Создайте первое уведомление.
5. Проверьте работу календаря и уведомлений.
