# Обзор продукта

## Назначение приложения

PupiloPlus предназначено для управления информацией о домашних питомцах и напоминаниями по уходу. Приложение сочетает в себе функции учёта данных о животном, визуального календаря и системы уведомлений.

## Основные сценарии использования

### 1. Учет питомцев
Пользователь может добавлять карточку животного с такими данными:

- имя;
- тип и порода;
- пол;
- дата рождения;
- цвет;
- вес;
- чип;
- особенности питания;
- заметки;
- фото.

### 2. Мониторинг возраста
По дате рождения приложение формирует возраст питомца. Для этого используется логика расчёта возраста, реализованная в классе `AgeCalculator`.

### 3. Планирование напоминаний
Пользователь может создавать события, такие как:

- кормление;
- лечение;
- вакцинация;
- уход и гигиена;
- другие регулярные действия.

### 4. Работа с календарём
На главном экране доступен календарь, который отображает дни с событиями. Это позволяет быстро увидеть, какие даты заняты напоминаниями.

## Основные экраны приложения

- Главный экран с календарём и списком питомцев;
- Профиль питомца;
- Добавление/редактирование питомца;
- Список напоминаний;
- Добавление/редактирование напоминания;
- Настройки приложения.

## Техническая логика

Приложение построено на базе Android SDK и использует:

- `SQLite` для хранения данных через `DatabaseHelper`;
- `RecyclerView` для списков;
- `Toolbar` и `Activity` для навигации;
- `NotificationHelper` и `NotificationScheduler` для напоминаний.

## Польза для пользователя

Приложение помогает систематизировать уход за питомцем и исключить забывание важных процедур. Такой подход особенно полезен для регулярных графиков приёма пищи, лечения и профилактических мероприятий.
