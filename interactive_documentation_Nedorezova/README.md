# Interactive Documentation — PupiloPlus (Nedorezova)

Кратко: комплект интерактивной документации в формате Markdown для приложения PupiloPlus.

Содержимое:
- `index.md` — главная страница, назначение и навигация.
- `quick-start.md` — быстрый старт с примерами и подсказками.
- `installation.md` — установка, проверка SHA, портативная версия, конфиг.
- `user-guide.md` — подробный пользовательский сценарий, примеры полей и экспорт.
- `reference.md` — команды CLI, формат экспорта/импорта, config.yaml.
- `screenshots.md` — все изображения с подписями и именами файлов.
- `faq.md` — часто задаваемые вопросы и быстрые решения.
- `troubleshooting.md` — пошаговая диагностика и команды для отладки.
- `images/` — все скриншоты и ресурсы из приложения.

Чек-лист требований (выполнено):
- Главная страница — есть (`index.md`)
- Не менее 4 тематических страниц — есть
- Навигация между разделами — есть
- Не менее 5 внутренних ссылок — есть
- Не менее 1 таблицы — есть (`installation.md`)
- Не менее 2 изображений — есть (много)
- Не менее 1 блока кода — есть (CLI/JSON/config примеры)
- Назначение продукта, инструкции по началу работы, руководство — есть

Сценарий демонстрации (5–7 минут):
1. Открыть `index.md` — показать назначение и навигацию.
2. Перейти в `quick-start.md` — выполнить 2–3 шага (создание заметки).
3. Показать `screenshots.md` — быстро пролистать изображения и подписи.
4. Открыть `reference.md` — показать экспорт/импорт JSON.
5. Показать `troubleshooting.md` и `faq.md` — быстрые ответы.
