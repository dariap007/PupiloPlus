# Устранение неполадок

## Проблема: Приложение не запускается

1. Убедитесь, что файл `PupiloPlus.exe` не заблокирован системой (свойства файла → Разблокировать).
2. Запустите приложение от имени администратора.
3. Проверьте журнал ошибок в `logs/` рядом с исполняемым файлом.

## Проблема: Ошибки при импорте данных

- Убедитесь, что формат JSON/CSV корректен и содержит необходимые поля.
- Если импорт падает — попробуйте открыть файл в текстовом редакторе и проверить кодировку (UTF-8).

## Проблема: Синхронизация не выполняется

- Проверьте доступность `sync.endpoint` (попробуйте открыть URL в браузере).
- Убедитесь, что на сервере синхронизации включены необходимые CORS/аутентификация.

## Шаги диагностики (пошагово)

### 1) Приложение не запускается

1. Запустите `PupiloPlus.exe` из командной строки, чтобы увидеть ошибки в stdout:

```powershell
cd "C:\Program Files\PupiloPlus"
.\PupiloPlus.exe
```

2. Если приложение падает с ошибкой DLL — проверьте наличие необходимых системных библиотек (Visual C++ Redistributable).
3. Проверьте файл `logs/error.log` рядом с исполняемым файлом — пришлите содержимое, если нужна помощь.

### 2) Ошибки при импорте

1. Откройте JSON-файл в текстовом редакторе и убедитесь, что он начинается с `[` и заканчивается `]`.
2. Проверьте наличие полей `id`, `title` и `text` для каждой записи.
3. Пример корректной записи см. в [Справочной информации](reference.md).

### 3) Уведомления не приходят

1. В Windows проверьте `Параметры` → `Система` → `Уведомления` и разрешите уведомления для `PupiloPlus`.
2. Убедитесь, что в `config.yaml` включены уведомления:

```yaml
notifications:
	enabled: true
	default_time_before: 10
```

3. Если приложение работает в фоне, убедитесь, что оно не завершает фоновые задачи системой энергосбережения.
