# Справочная информация

## Командная строка

```text
--help                 вывести справку
--export <file>        экспортировать данные в файл (JSON/CSV)
--import <file>        импортировать данные из файла (JSON/CSV)
--sync                 запустить синхронизацию с облаком
--create-sample        создать демонстрационные данные
```

Примеры использования:

```bash
./PupiloPlus.exe --export backup.json
./PupiloPlus.exe --import backup.json
```

## Параметры конфигурации

Формат конфигурации — `config.yaml`.

| Параметр | Описание | Пример |
|---|---|---|
| `sync.enabled` | Включает синхронизацию (true/false) | `false` |
| `sync.endpoint` | URL сервера синхронизации | `https://sync.example.com` |
| `notifications.enabled` | Включает локальные уведомления | `true` |
| `notifications.default_time_before` | Время оповещения до события (минуты) | `10` |

## Экспорт/импорт

- Экспорт формата JSON содержит список заметок с полями `id`, `title`, `text`, `tags`, `reminder`.
- CSV экспорт содержит столбцы `id,title,text,tags,reminder`.

### Примеры содержимого JSON-экспорта

```json
[
	{
		"id": "note-001",
		"title": "Домашнее задание по математике",
		"text": "Решить упражнения 5-10",
		"tags": ["учёба","математика"],
		"reminder": "2026-10-20T18:00:00"
	},
	{
		"id": "note-002",
		"title": "Визит к врачу",
		"text": "Записаться на приём",
		"tags": ["здоровье"],
		"reminder": null
	}
]
```

### Типичные сценарии использования команд CLI

- Экспорт всех данных в `backup.json` перед переустановкой системы:

```bash
./PupiloPlus.exe --export backup.json
```

- Импорт сохранённых данных после установки на новом компьютере:

```bash
./PupiloPlus.exe --import backup.json
```

### Параметры синхронизации

- `sync.enabled: true` — включает фоновые задачи синхронизации.
- `sync.endpoint` — адрес сервера; если используется облачный сервис, укажите URL API.

Если вы не используете синхронизацию, оставьте `sync.enabled` в `false` для защиты приватности и уменьшения сетевой активности.
