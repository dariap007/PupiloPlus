# FAQ — Часто задаваемые вопросы

## Вопрос: Как восстановить удалённую заметку?

Если вы сделали экспорт ранее — импортируйте файл экспорта. В противном случае удалённые записи нельзя восстановить из локального хранилища, если не включено резервное копирование.

## Вопрос: Можно ли синхронизировать данные между устройствами?

Да — для этого включите `sync.enabled` в `config.yaml` и укажите рабочий `sync.endpoint`. Синхронизация требует наличия сервера или облачного решения.

## Вопрос: Какие форматы импорта/экспорта поддерживаются?

Поддерживаются JSON и CSV.

## Вопрос: Почему не приходят уведомления?

Проверьте системные настройки уведомлений и параметры в `config.yaml` (`notifications.enabled`). На Windows проверьте разрешения для приложения в системных настройках.

## Дополнительные вопросы

### Как сделать резервную копию всех заметок?

1. Откройте меню `Файл` → `Экспорт` → выберите `JSON`.
2. Сохраните файл в безопасное место (внешний диск или облако).

### Как найти заметку по метке?

1. Нажмите в строке поиска на значок фильтра.
2. Введите имя метки или выберите из списка.

### Как изменить язык интерфейса?

В текущей версии доступен только русский интерфейс. Для смены языка в будущих версиях используйте `Настройки` → `Язык`.
