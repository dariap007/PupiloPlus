# Справочная информация

## Ключевые сущности приложения

| Компонент | Назначение |
|---|---|
| `Pet` | Данные о питомце |
| `Reminder` | Данные о напоминании |
| `DatabaseHelper` | Работа с локальной SQLite-базой |
| `CustomCalendarView` | Отображение календаря и дат |
| `NotificationScheduler` | Планирование уведомлений |
| `SettingsActivity` | Настройки интерфейса и уведомлений |

## База данных

Данные приложения сохраняются локально в SQLite. Это позволяет хранить карточки питомцев и напоминания даже без подключения к интернету.

## Пример кода

```java
public class AgeCalculator {
    public static String calculateAge(String birthDate) {
        // расчет возраста по дате рождения
        return "2 года";
    }
}
```

Этот пример показывает, как приложение рассчитывает возраст питомца на основе даты рождения.

## Ограничения и особенности

- приложение работает локально на устройстве;
- изображения сохраняются в файловой системе устройства;
- напоминания зависят от заданного времени и разрешений Android;
- для полноценной работы необходимо корректно настроить уведомления.
