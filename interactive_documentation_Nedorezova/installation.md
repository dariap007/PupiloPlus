# Установка и настройка

## Системные требования

| Параметр | Минимальное значение | Рекомендуемое значение |
|---|---:|---:|
| Операционная система | Windows 10 | Windows 11 |
| Оперативная память | 2 ГБ | 4 ГБ |
| Свободное место | 200 МБ | 500 МБ |

## Загрузка и проверка

1. Скачайте архив или установщик с защищённого источника.
2. (Опционально) Проверьте контрольную сумму SHA256, если она предоставлена.

```powershell
Get-FileHash .\PupiloPlus-installer.exe -Algorithm SHA256
```

## Установка

1. Запустите `PupiloPlus-installer.exe` и следуйте мастеру.
2. Выберите папку установки и параметры ярлыков.
3. При необходимости разрешите приложению отправлять уведомления.

### Портативная версия

1. Распакуйте архив в удобную папку.
2. Запустите `PupiloPlus.exe` (не требуется установка в систему).

## Файлы конфигурации

Пример файла конфигурации `config.yaml`:

```yaml
sync:
	enabled: false
	endpoint: "https://sync.example.com"
notifications:
	enabled: true
	default_time_before: 10 # минут
```

## Удаление и обновление

- Удаление: используйте стандартный деинсталлятор Windows или удалите папку портативной версии.
- Обновление: скачайте новую версию и выполните установку поверх старой (при необходимости сделайте резервную копию данных).

## Пошаговая установка с пояснениями (GUI)

1. Двойной клик по `PupiloPlus-installer.exe`.
2. Разрешите запуск, если Windows показывает предупреждение SmartScreen.
3. На шаге `Выбор папки` нажмите `Далее` (рекомендуется путь по умолчанию: `C:\Program Files\PupiloPlus`).
4. На шаге `Компоненты` выберите создать ярлык на рабочем столе, если нужно.
5. Нажмите `Установить` и дождитесь завершения.

После установки:

- Запустите приложение и проверьте, открывается ли главное окно.
- Если приложение не запускается — откройте `Просмотр событий Windows` → `Приложения`, проверьте ошибки, связанные с `PupiloPlus`.

## Проверка работоспособности после установки

1. Создайте тестовую заметку и напоминание (см. [Быстрый старт](quick-start.md)).
2. Выполните экспорт данных в JSON (`Файл` → `Экспорт`) и проверьте файл на корректность.

Если что-то пошло не так, смотрите раздел «Устранение неполадок» в `troubleshooting.md`.
