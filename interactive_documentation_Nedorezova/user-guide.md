# Руководство пользователя

## Навигация по приложению

Интерфейс состоит из трёх основных областей:

- Панель управления (верхняя) — быстрый доступ к созданию записи, фильтрам и настройкам;
- Список записей — основная рабочая область для просмотра и выбора заметок;
- Форма редактирования — поля для заголовка, текста, меток и даты напоминания.

## Создание заметки — подробная инструкция

1. Нажмите «+» в правом верхнем углу.
2. Заполните поле `Заголовок` (обязательно) и `Текст`.
3. Добавьте метки (через запятую) для удобной фильтрации.
4. Установите дату и время напоминания (опционально).
5. Нажмите `Сохранить`.

Пример заполнения:

- Заголовок: "Домашнее задание по математике"
- Текст: "Решить упражнения 5–10 на странице 32"
- Метки: `учёба, математика`
- Напоминание: 2026-10-20 18:00

### Пример экспорта заметки (JSON)

```json
{
	"id": "note-001",
	"title": "Домашнее задание по математике",
	"text": "Решить упражнения 5-10",
	"tags": ["учёба","математика"],
	"reminder": "2026-10-20T18:00:00"
}
```

### Редактирование и удаление

- Редактировать: откройте заметку и нажмите `Редактировать` — внесите изменения и сохраните.
- Удалить: выберите `Удалить` и подтвердите. Удалённые элементы можно восстановить из резервной копии, если включён экспорт.

### Фильтры и поиск

- Поиск по заголовку и тексту.
- Фильтрация по меткам и дате.

### Горячие клавиши

- `Ctrl+N` — создать новую заметку
- `Ctrl+F` — открыть поиск

## Подробное описание полей формы заметки

- `Заголовок` (обязательно): короткая фраза, описывающая суть заметки. Рекомендуется до 80 символов.
- `Текст`: подробное описание задачи или заметки. Можно использовать простое Markdown-разметку для выделения кода или команд.
- `Метки`: ключевые слова, разделённые запятыми; используются для фильтрации и быстрого поиска.
- `Напоминание`: дата и время; при задании времени также можно указать повтор (ежедневно, еженедельно).

### Пошаговый пример: создать напоминание о сдаче отчёта

1. Нажмите `+` → выберите «Создать заметку».
2. В поле `Заголовок` введите: `Сдать отчёт по практике`.
3. В поле `Текст` опишите: `Подготовить отчёт и прикрепить файлы`.
4. В `Метки` добавьте: `учёба, отчёт`.
5. В `Напоминание` выберите дату и время: через 3 дня в 09:00.
6. Нажмите `Сохранить`.

Результат: заметка появится в списке, а в указанное время система покажет уведомление.

### Как использовать метки для быстрой фильтрации

1. Нажмите значок фильтра.
2. Выберите одну или несколько меток из списка.
3. Нажмите `Применить` — в списке останутся элементы только с выбранными метками.

### Советы по организации заметок

- Используйте короткие и однозначные метки (например, `учёба`, `дом`, `работа`).
- Часто используемые метки можно закреплять в верхней панели.
- Для важных задач используйте напоминания и добавляйте имя ответственного (если применимо).
